
# 📊 Organizador de Imposto de Renda — Excel

O Organizador de Imposto de Renda é uma planilha desenvolvida em Excel com o objetivo de auxiliar na organização das informações necessárias para a Declaração do Imposto de Renda Pessoa Física (IRPF), facilitando o controle de rendimentos, despesas, bens e dados do contribuinte ao longo do ano.

---

## 🚀 Funcionalidades
🧾 Organização dos dados do contribuinte  
💰 Controle de rendimentos tributáveis  
💸 Registro de rendimentos isentos e não tributáveis  
📉 Controle de despesas dedutíveis  
🏠 Cadastro de bens e direitos  
📊 Consolidação das informações para conferência  
🗂️ Centralização dos dados em um único arquivo  

---

## 🧮 Como funciona
O usuário registra na planilha:

Dados pessoais do contribuinte  
Rendimentos recebidos ao longo do ano  
Despesas dedutíveis (saúde, educação, entre outras)  
Bens, direitos e valores atualizados  

Com base nesses dados, o organizador:

Facilita a visualização e conferência das informações  
Auxilia na preparação para o preenchimento do programa da Receita Federal  
Reduz riscos de omissões e inconsistências na declaração  

🛠️ Tecnologias Utilizadas
Microsoft Excel  
Fórmulas e funções nativas  
Organização de dados em planilhas  

## ⚠️ Observações
Este organizador não substitui o programa oficial da Receita Federal.  
Os dados devem ser preenchidos com base em documentos oficiais.  
Para casos mais complexos, recomenda-se o apoio de um contador.
